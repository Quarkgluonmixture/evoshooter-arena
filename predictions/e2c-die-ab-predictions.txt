# E2c — 给了私有骰子，进化会捡起来吗？
# 冻结时间：2026-09-19（写在 `--die 1` 的任何一次训练被读之前；通道本身已 ship 且默认关）

## 这次问的不是 demand

E2 已经量过 demand（混合值 +14.5pp），E2b 量过供给（恒为 0.000 bit，底座里没有这条自由度）。
E2c 只问一件事：**把自由度补上之后，选择压力会不会真的把它用起来。**
⛔ 通道存在 ≠ 进化会用 —— 这正是 DISCOVERY 合同 claim ladder 的第一级。

## A/B 的形状与它的已知弱点（先写下来）

- **对照臂** = `runs/d2-long-s{1,2}.json`（已训完，`privateDieDim` 0）。
- **处理臂** = 同配置 + `--die 1`，同样 seed 1 / 2、300 代。
- ⚠⚠ **这不是配对实验（坑 #27）**：加一维 observation ⇒ genome 5324→5364 ⇒ 初始种群本来就不同。
  ⇒ **只读方向，⛔ 不读效应量**；2 个 seed 的行为侧 A/B 按 CHECKPOINT ④ 也只允许读方向。
- ⭐ **跨边界的合法尺子是 `yardstick`**：`privateDieDim` 已进 `BRAIN_ONLY_FIELDS`，
  且 `tests/world.test.ts` 机械验证过「改它不改手写 bot 的那场比赛（逐位）」⇒ 手写 bot 两边玩的是同一个游戏。
  ⛔ `crossplay` 跨臂**不可用**（genome 长度不同，它会硬报错，这是对的）。

## 预测（冻结）

P1 ⭐ **主 exit（供给侧）**：处理臂在 `npm run mixing` 的 **arm A** 上，四个冠军里**至少一个**读到 > 0.1 bit。
   ⚠ **我押它不成立。** 理由：混合只对**会best-respond 的对手**兑现（E2 实测），而 16 个体 × 300 代的
   共演化在 `exploit` 下四个目标只打穿一个 ⇒ 这个预算里「可预测」几乎不受惩罚，骰子上的权重就只是漂移。
   ⇒ 我的点预测：**四个冠军的 arm A 中位数仍是 0.000**，最多一个格子有非零。
P2 ⭐⭐ **混合 vs 噪声必须分开**：若 arm A > 0，同时看 **distinct plans**。
   真混合 = **少数几个计划 + 稳定比例**（32 场里 distinct ≤ 4）；把骰子当噪声用 = distinct 很大（≥ 12）、熵往 5 bit 爬。
   ⛔ 只报熵不报 distinct 的读数不构成「学会了混合」。
P3 **不退步**：`yardstick` 上处理臂的冠军对手写 bot 胜率，与对照臂**同向可比**（⛔ 不读效应量）。
   若处理臂明显更差，那是「多一维输入吃掉了搜索预算」，也是结论。
P4 描述项（⛔ 不判闸）：骰子那一列输入权重的 L2，与其它输入列的均值相比。
   ⚠ 无选择的漂移会把它留在初始化尺度附近 ⇒ **这条分辨力很弱，只作描述**，⛔ 不拿它证明「用了/没用」。

## exit 与它的两个方向

- **P1 成立**（骰子被捡起来）⇒ 下一步是问**值不值**：`yardstick` + 一个会 best-respond 的对手（`exploit`）。
- **P1 不成立**（大概率）⇒ ⛔ **不许得出「私有骰子没用」**。正确的结论只有一句：
  **在这个预算、这个对手分布下，不可预测性没有回报。** 这恰好把矛头指回 **E6 对手生态** ——
  E2 的表早就说了混合只对会适应的对手兑现。⇒ 通道保留、默认关，等生态立起来再复测。
  （VISION §14.2：回退实现，不回退现象。）

## ⛔ 事先写死的边界

⛔ 不因为 P1 失败就加大骰子维度、改 fitness、或给混合发糖（那是 VISION §10 明禁的 shaping）。
⛔ 不拿处理臂和对照臂跑 `crossplay`（规则集不同，工具会拒绝，别绕过它）。
⛔ 2 个 seed，只读方向。

## Addendum 1（2026-09-19，写在两条 `--die 1` 长跑被读之前；只看过冒烟与对照）

**P1 写错了，而且错得很基本：零假设不是零。**

冒烟（`runs/smoke-die.json`，3 代 × pop 8，⛔ 不作任何结论）读到：
一个**只训了 2 代**的随机网络，arm A 已经读 **1.703 bit / 16 场里 4 个不同计划**。
原因显而易见、事先却没想到：**随机权重本来就会把骰子透传出去。** 骰子每场都变 ⇒ 计划每场都可能变。
⇒ 「arm A > 0.1 bit」这条 exit **一个没学过的网络就能满足**，它量的是通道存在，不是进化用了它。

⭐ **同一次冒烟也把仪器那一半钉死了**（这条成立）：新增的 `ctl die-reader`
（手写守方，从**自己 observation 的尾巴**读骰子决定去哪个点，走的就是大脑拿到的那几个字节）
读 **3.453 bit / 12 个计划** ⇒ **通道确实送达策略**。
⇒ 以后若冠军读 0.000，那是**进化的结论**，不是仪器坏了。这正是加它的理由。

### 替换后的读法（仍在读长跑之前冻结）

**P1'（主 exit，改为同一条 run 的 gen 0 对照）**：比 `--gen 0` 与 `--gen 299` 的
**(熵, distinct plans)** 这一对。骰子在两代都在、选择只作用于后者 ⇒ gen 0 就是这条 run 自己的零假设。
- **朝混合走** = distinct **下降**到少数几个（≤ 4/32）而熵**没有跟着塌到 0** ⇒ 从抖动收敛成**几个计划**。
- **朝抖动走** = distinct 维持高位（≥ 12/32），熵往 log2(32) 爬 ⇒ 骰子只是噪声。
- **被压制** = 熵与 distinct **双双向 0 掉** ⇒ ⭐ 选择**主动削掉**了骰子的影响
  （「不可预测」在这个对手分布下不但不赚，还伤自己的配合）。
⚠ 三种走向我押**第三种**（压制）或第二种（维持抖动），⛔ 押第一种不成立。

**P2 不变**（distinct 必须和熵一起读）。**P3 不变**（`yardstick` 只读方向）。
**P4 已被冒烟降级**：die 列 L2 与其它输入均值之比在 gen 2 就是 0.92–0.96×（= 初始化尺度）
⇒ 如预料地没有分辨力，⛔ 只留作记录。

⛔ **旧 P1 不再作数，也不许事后改回来读**；上面这条是它的替代。

**合法**骰值，通道仍在、只是不再变；⛔ 不是清零，清零是 OOD，坑 #24）⇒
**8 个格子全部塌回 0.000 / 1 plan。** ⇒ **计划的变化就是骰子造成的**，不是「末代权重更大所以更敏感」。

⭐ **但长出来的不是「队的混合计划」，是「每个人各自掷」**。计划集合按独立逐 slot 翻转**几乎精确可分解**：
